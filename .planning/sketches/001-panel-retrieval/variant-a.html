Panel retrieval sketch · Variant A of 2

Retrieval-first: one search, ranked objects + fields

Thesis: the panel metaphor isn't broken, findability is. Data and Contents collapse into a single search entry point in the topbar. Typing a name or an intent word ranks accounts and their individual fields together, and picking a result lands the cursor directly in that control — no panel name to guess first.

The test: "Mark the Roth's value as an estimate"

Press Ctrl K (or click the search bar) → type roth → click Roth IRA — Dana → Value in the ranked results.

3 actions: open, type, select. Cursor lands in the Value input, focused, caption field visible right below it for the estimate note.

What this deletes

  • The Data panel as a place you browse — no more opening a full form and scrolling to find a section.
  • The second, separate Contents filter box — one search box now, not two.
  • The Add / Data / Contents / Help four-icon rail — down to two rail icons (Add, Help); search lives in the topbar as the front door.
  • Panel names as a thing you need to know at all — you never choose "Data" vs "Contents" again.
